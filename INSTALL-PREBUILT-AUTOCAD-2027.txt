CISC Steel Shapes - Easy Install Without Building
=================================================

For AutoCAD 2027 users, download the one-click installer:

  prebuilt/AutoCAD-2027/CISC-Steel-Shapes-Installer-AutoCAD-2027.exe

Close AutoCAD, run the EXE, then open AutoCAD and type:

  CISCINSERT

Manual fallback:

  prebuilt/AutoCAD-2027/CISCSections.bundle.zip

The manual ZIP contains the current files:

  CISCSections.bundle/PackageContents.xml
  CISCSections.bundle/Contents/CISCSections.dll
  CISCSections.bundle/Contents/LoadCISC.lsp

Full instructions:

  prebuilt/AutoCAD-2027/README-INSTALL.txt

These install methods do not require Visual Studio or the .NET SDK.
They are intended for full AutoCAD 2027, not AutoCAD LT.

Layer mapping:

  - Solid / visible lines: layer 6
  - Hidden lines: layer 5
  - Centre lines: layer 3
