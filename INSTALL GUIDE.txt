CISC METRIC SECTIONS - AUTOCAD 2027 INSTALL GUIDE
==================================================

Command after install:

  CISCINSERT


EASY METHOD - FOR NORMAL USERS
==============================

1. Open the latest GitHub release:

   https://github.com/sal96422-lab/CISC-Steel-Shapes/releases/latest

2. Download only this file:

   CISC-Steel-Shapes-Installer-AutoCAD-2027.exe

3. Close AutoCAD completely.

4. Double-click the EXE.

5. Do not run as Administrator unless AutoCAD is also opened as Administrator.

6. Open AutoCAD 2027.

7. If AutoCAD asks whether to load the plugin or LoadCISC.lsp, choose:

   Always Load

8. Type:

   CISCINSERT


MANUAL METHOD - WITHOUT EXE
===========================

Use this if the EXE is blocked by company security.

1. Download:

   prebuilt/AutoCAD-2027/CISCSections.bundle.zip

2. Extract the ZIP.

3. Press Windows key + R.

4. Paste this path and press Enter:

   %APPDATA%\Autodesk\ApplicationPlugins

5. Copy the extracted folder named CISCSections.bundle into that ApplicationPlugins folder.

6. Confirm these files exist:

   %APPDATA%\Autodesk\ApplicationPlugins\CISCSections.bundle\PackageContents.xml
   %APPDATA%\Autodesk\ApplicationPlugins\CISCSections.bundle\Contents\CISCSections.dll
   %APPDATA%\Autodesk\ApplicationPlugins\CISCSections.bundle\Contents\LoadCISC.lsp

7. Open AutoCAD 2027.

8. Type:

   CISCINSERT


ADVANCED METHOD - BUILD FROM SOURCE
===================================

Use this only if you want to build the plugin yourself.

Requirements:

  - Full AutoCAD 2027, 64-bit
  - Visual Studio 2022 with .NET desktop development, or the .NET 10 SDK

Run this from the repository folder:

  powershell -ExecutionPolicy Bypass -File .\Build-And-Install.ps1

The script builds the DLL, copies the full bundle, adds LoadCISC.lsp to
APPLOAD Startup Suite, and registers CISCINSERT for AutoCAD demand-loading.


TROUBLESHOOTING
===============

Problem:

  Unknown command: CISCINSERT

Try:

  1. Confirm the user is using full AutoCAD 2027, not AutoCAD LT.
  2. Confirm the EXE was run as the same Windows user who opens AutoCAD.
  3. In AutoCAD, run NETLOAD and select:

     %APPDATA%\Autodesk\ApplicationPlugins\CISCSections.bundle\Contents\CISCSections.dll

  4. Then type CISCINSERT again.


LAYERS
======

The plugin uses existing layers in the drawing:

  Solid / visible lines: layer 6
  Hidden lines: layer 5
  Centre lines: layer 3


SECTION DATA
============

The section data is embedded in the plugin. No separate spreadsheet or database
is required on the user's computer.
